## Brand & Style

The design system establishes a high-trust, mission-driven SaaS environment built to support community-scale resource circulating and systemic waste diversion. The design tone combines institutional reliability with modern environmental stewardship—positioning ecological sustainability not as a grassroots compromise, but as an optimized, premium utility.

### Visual Style
- **Aesthetic Direction:** Refined Ecological SaaS. Clean surfaces, surgical contrast, crisp structure, and tactile micro-affordances.
- **Atmosphere:** Intentional, uncluttered, highly systematic, and luminous.
- **Key Principles:**
  - **Pragmatic Utility:** Data dense yet unhurried. Metrics and inventory take priority over gratuitous ornamentation.
  - **Purposeful Color Attribution:** Color is functional, designating status, asset availability, and urgency rather than decorative fills.
  - **Calibrated Restraint:** Soft elevation boundaries, generous interior card paddings, and precise slate line work.

## Colors

The palette leverages a deep botanical anchor paired with vital emerald accents and a rigorous, neutral slate structural ladder. Contrast ratios meet or exceed WCAG AAA standards for all standard text elements.

### Color Tokens & Roles

- **Primary (`#1B4332` - Forest Deep):** The foundational anchor. Used for high-emphasis callouts, primary buttons, major headline accents, and selected sidebar states.
- **Secondary (`#10B981` - Emerald Bright):** Interactive focal points, positive metrics, conversion accents, and live activity indicators.
- **Tertiary (`#059669` - Emerald Deep):** Interactive hover states for secondary elements, high-contrast badges, and progress bar tracks.
- **Neutral Dark (`#0F172A` - Slate 900):** Primary headers, high-contrast typography, and core iconography.
- **Neutral Secondary (`#1E293B` - Slate 800) & Muted (`#64748B` - Slate 500):** Secondary data columns, supporting labels, meta information, and placeholder text.
- **Surfaces & Canvases:**
  - Application Canvas: `#F8FAFC` (Slate 50)
  - Card & Container Surface: `#FFFFFF` (Pure White)
  - Muted Inset / Table Header Surface: `#F1F5F9` (Slate 100)
- **Borders & Dividers:**
  - Primary Structural Stroke: `#E2E8F0` (Slate 200)
  - Subtle / Inset Stroke: `#F1F5F9` (Slate 100)
- **Functional Semantics (Light Pill Background / Deep Text Accent):**
  - Success / Active: `#ECFDF5` / `#047857`
  - Pending / Warning: `#FFFBEB` / `#B45309`
  - In Progress / Informational: `#EFF6FF` / `#1D4ED8`
  - Urgent / Danger / Rejected: `#FEF2F2` / `#B91C1C`

## Typography

The design system uses **Plus Jakarta Sans** uniformly across display, structural headers, data grids, and micro-labels. Its modern geometric backbone combined with subtle humanities ensures crisp clarity at compact table sizes and authoritative distinction within quantitative analytics.

### Hierarchy Guidelines
- **Metrics & KPIs:** Use `display-stat` exclusively for quantitative hero numbers (e.g., kilograms of waste averted, active community rentals). Never use this scale for prose headings.
- **Section Headers:** Use `headline-lg` for primary top-level views and dashboard cards; reserve `headline-xl` for global workspace breadcrumbs and major modal titles.
- **Table Data & Forms:** Standardize on `body-md` for row items, input field values, and dropdown menus. Use `body-sm` for field helper labels and contextual footnotes.
- **Pills & Metas:** Standardize on `badge-micro` with full uppercase transformation for role tags, asset availability, and priority matrices.

## Layout & Spacing

The layout is architected around an administrative web application shell featuring a fixed navigation sidebar, an interactive utility header, and an elastic, multi-column dashboard grid.

### Application Shell Structure
- **Global Sidebar:** Fixed 260px desktop width. Collapses to an icon-only 72px rail on tablet viewport (`768px - 1024px`) and transitions to an off-canvas drawer on mobile (`< 768px`).
- **Main Viewport Canvas:** Employs an adaptive 12-column grid system bounded by a max-width container of 1600px with dynamic exterior margins (`margin` for desktop, `margin-mobile` for viewports under 768px).
- **Gutter Distribution:** `gutter` (24px) on desktop viewports; drops to `gutter-mobile` (16px) on mobile viewports.

### Spacing Scale & Rhythm
- Spacing relies on a clean 4px/8px modular rhythm.
- `space-xs` (8px) and `space-sm` (12px) govern internal input control paddings, badge gutters, and icon-to-label gaps.
- `space-md` (16px) and `space-lg` (24px) govern card bodies, stack layouts, and widget interiors.
- `space-xl` (32px) and `space-2xl` (48px) separate macroscopic dashboard rows and visual modules.

## Elevation & Depth

Visual hierarchy uses a refined hybrid of tonal layering and soft, ambient drop shadows. Surfaces communicate depth through subtle separation rather than high-contrast drops.

### Elevation Levels

- **Level 0 (Flat Canvas / Recessed):**
  - Background: `#F8FAFC`
  - Shadow: None
  - Stroke: None or `#F1F5F9`
  - Usage: Global application frame, empty states, and sunken metric tracks.

- **Level 1 (Card & Content Surface):**
  - Background: `#FFFFFF`
  - Stroke: 1px solid `#E2E8F0`
  - Shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.02)`
  - Usage: Standard dashboard cards, list containers, and data table housings.

- **Level 2 (Interactive Floating / Hover State):**
  - Background: `#FFFFFF`
  - Stroke: 1px solid `#CBD5E1`
  - Shadow: `0 4px 6px -1px rgba(15, 23, 42, 0.06), 0 2px 4px -2px rgba(15, 23, 42, 0.03)`
  - Usage: Card hovers, search autocomplete menus, and active filter panels.

- **Level 3 (Overlays & Dialogs):**
  - Background: `#FFFFFF`
  - Stroke: 1px solid `#E2E8F0`
  - Shadow: `0 20px 25px -5px rgba(15, 23, 42, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`
  - Backdrop: `rgba(15, 23, 42, 0.40)` with `blur(4px)`
  - Usage: Modal dialogs, slide-over asset inspection panels, and confirmation alerts.

## Shapes

The interface balances sharp productivity with welcoming community accessibility through geometric roundedness (`roundedness: 2`).

### Geometry Rules
- **Base Components (Inputs, Buttons, Segmented Controls):** `rounded` (0.5rem / 8px). Creates crisp, click-target definitions that remain soft to the eye.
- **Card Containers & Data Panes:** `rounded-lg` (1rem / 16px). Distinguishes content modules without creating excessive dead space at card intersections.
- **Modal Dialogs & Slide-overs:** `rounded-xl` (1.5rem / 24px). Elevates key overlay containers to feel premium and self-contained.
- **Pills, Badges & Avatars:** Fully rounded (`rounded-full` / 9999px). Used for user profiles, category chips, status labels, and count indicators.

## Components

### Buttons & Interactive Controls
- **Primary Button:** `#1B4332` background with `#FFFFFF` text. Hover state switches to `#143326` with a micro-scale shift (`scale: 0.99`). Focus ring uses a 2px offset with `ring-2 ring-emerald-500`.
- **Secondary Button:** `#FFFFFF` background with 1px border `#E2E8F0` and `#0F172A` text. Hover applies `#F8FAFC` background and `#CBD5E1` border stroke.
- **Accent/Action Button:** `#10B981` background with `#FFFFFF` text. Used exclusively for conversion steps such as "Borrow Item" or "Log Diversion."

### Form Inputs & Search Fields
- **Container Structure:** Standard height of 40px (desktop), 1px solid `#E2E8F0` border, `#FFFFFF` surface, and 8px corner radius.
- **Focus Paradigm:** Distinct 2px halo: `border-color: #10B981; box-shadow: 0 0 0 3px rgba(16, 185, 129, 0.15)`. No default browser outlines.
- **Search Header Input:** Includes an inset left-aligned search icon (`#64748B`) and a keyboard shortcut badge (`⌘K`) anchored to the right edge.

### Status Badges & Category Chips
- Built using `rounded-full`, 4px vertical padding, 10px horizontal padding, and strict font sizing (`label-sm` or `badge-micro`).
- **Available / Shared:** Surface `#ECFDF5`, text `#047857`, with a 6px solid emerald status dot.
- **In-Review / Reserved:** Surface `#FFFBEB`, text `#B45309`, with a 6px solid amber status dot.
- **Active Loan:** Surface `#EFF6FF`, text `#1D4ED8`, with a 6px solid royal blue status dot.
- **Decommissioned / Urgent:** Surface `#FEF2F2`, text `#B91C1C`, with a 6px solid rose status dot.

### Data Tables
- **Header Cell:** `#F8FAFC` background, 1px bottom border `#E2E8F0`, uppercase text styled with `label-sm` in `#64748B`.
- **Row Body:** Height of 52px, alternating or white surface, 1px divider `#F1F5F9`. Hover transition applies `#F8FAFC` smoothly.
- **Numeric & Metric Cells:** Monospaced tabular alignment (`font-variant-numeric: tabular-nums`) right-aligned against matching header columns.

### Dashboard Stats Widgets
- Self-contained Level 1 card surface with 20px padding.
- Consists of:
  1. Top utility row containing the contextual title (`label-md` in `#64748B`) and a subtle rounded icon container (surface `#ECFDF5`, icon `#059669`).
  2. Large primary metric using `display-stat` in `#0F172A`.
  3. Bottom meta row with positive/negative trend pill (e.g., `+12.4% vs last month` in `#047857`) and benchmark baseline text.
